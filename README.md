# 🩺 DocAppoint – Doctor Appointment Manager

An advanced, modern, and user-friendly single-page application (SPA) designed to bridge the gap between patients and healthcare professionals. **DocAppoint** streamlines the entire process of searching for doctors, viewing their schedules, and securely booking appointments online.

---

# 🎯 Core Purpose

The primary goal of **DocAppoint** is to eliminate the complexities of traditional doctor appointment systems. This platform allows patients to easily find the right specialist doctors from the comfort of their homes and book, update, or cancel appointments in real time without any hassle.

---

# 👥 Target Audience

### • General Patients
People who are looking for trusted and top-rated doctors for proper diagnosis and treatment.

### • Busy Professionals
Individuals who do not have enough time to physically visit hospitals and wait in long queues for appointments.

### • Doctors & Hospital Authorities
Healthcare providers who want to digitize and efficiently manage their appointment scheduling system.

---

# ✨ Key Features

## 🔐 Secure BetterAuth Authentication
- Secure login and registration system using JWT and session-based authentication
- One-click social login with Google and GitHub

## 📈 Dynamic Hero Section & Top-Rated Doctors
- Interactive homepage banner slider
- Dynamic display of the top 3 highest-rated doctors based on patient reviews

## 🔍 Advanced Search & Filtering
- Search functionality on the “All Appointments” page to quickly find appointments by doctor name

## 📅 Real-Time Appointment Booking Modal
- Book appointments directly from the doctor details page using a modal form without page refresh

## 🛠️ Personalized Dashboard (Private Route)

### • My Bookings
- View all booked appointments
- Instantly update appointment data through modal forms without refreshing the page
- Delete appointments easily

### • My Profile
- Instantly update user name and profile picture

## 🌓 Theme Toggle & Fully Responsive Design
- Clean and modern UI design
- Fully responsive across mobile, tablet, and desktop devices
- Includes Dark/Light mode toggle system

## 🚀 Reload Resilience & SEO Friendly
- Users remain logged in even after refreshing private routes in the SPA architecture
- Proper metadata added to every page for better SEO optimization
